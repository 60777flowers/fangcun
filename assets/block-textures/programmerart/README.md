ProgrammerArt
=============

Original textures designed for voxel games, freely released for any use.

Upstream: https://github.com/deathcap/ProgrammerArt
License: Creative Commons Zero 1.0 Universal Public Domain Dedication (see LICENSE)

This directory vendors a small subset of the `blocks/` textures (16x16 PNG) so the
repository builds offline. `npm run atlas` composes them into the Android texture atlas.
See docs/BLOCK-TEXTURES.md for the mapping format and how to swap in another pack.
